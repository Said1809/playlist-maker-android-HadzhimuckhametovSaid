# Playlist Maker

Приложение для поиска музыки через iTunes API, создания плейлистов и управления списком избранных треков.

## Описание проекта
Playlist Maker — это учебный проект, демонстрирующий современные подходы к разработке под Android:
- Архитектура MVVM с четким разделением на слои (Data, Domain, UI).
- Современный UI на базе Jetpack Compose.
- Работа с сетью через Retrofit.
- Хранение данных в локальной базе данных Room.
- Реактивное программирование с использованием Kotlin Coroutines и Flow.

## Технологии и версии
- **Android Studio**: Ladybug 2024.2.2 или выше.
- **Kotlin**: 2.0.21.
- **Compose**: 2024.10.00 (BOM).
- **Target SDK**: 36.
- **Min SDK**: 24.
- **База данных**: Room 2.6.1.
- **Сеть**: Retrofit 2.11.0.

## Инструкция по сборке и запуску
1. Склонируйте репозиторий.
2. Откройте проект в Android Studio.
3. Дождитесь завершения синхронизации Gradle.
4. Убедитесь, что в файле `local.properties` корректно указан путь к вашему Android SDK.
5. Для сборки через терминал выполните:
   ```bash
   ./gradlew assembleDebug
   ```
6. Нажмите кнопку **Run** в Android Studio для запуска приложения на эмуляторе или физическом устройстве.
